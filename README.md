# 🥌 📄 ✂️ Piedra, Papel o Tijera

Juego web interactivo desarrollado en JavaScript donde el usuario compite contra la computadora al mejor de 3 victorias.

## Arquitectura y Lógica
* **Condicionales y Flujo Control:** Manejo de reglas de juego y validación de estados (victoria, derrota, empate).
* **Manejo del DOM:** Actualización dinámica de puntuaciones y mensajes sin recargar la página.
* **Aleatoriedad:** Selección automatizada de jugadas para el bot mediante algoritmos matemáticos en JS.

## Tecnologías Utilizadas
* HTML5
* CSS3
* JavaScript (ES6+)

## Métricas del Proyecto (MVT / Analytics)
* Partidas completadas por sesión de usuario.
* Tasa de retención y tiempo en pantalla.
* Distribución de resultados (porcentaje global de victorias/derrotas).

## Funcionalidades Futuras (Roadmap)
* Implementación de animaciones para la selección de opciones.
* Historial de partidas guardado en LocalStorage.
* Modo multijugador local en la misma pantalla.
